# BSIT Professional Portfolio

Static portfolio website for GitHub Pages.

- `index.html`: website entry point.
- `assets/`: screenshots, study materials, résumé, mock interview video and project documentation.
- `.nojekyll`: tells GitHub Pages to serve the static site directly.

**Published address:** https://frostner.github.io/ferick-portfolio/

To update the existing GitHub repository, replace the root `index.html` and add the `assets` folder and `.nojekyll` file. Leave GitHub Pages publishing from `main` and `/(root)`.
