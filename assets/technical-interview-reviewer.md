# TECHNICAL INTERVIEW PREPARATION — STEP 20

These are short practice answers. Explain them in your own words and demonstrate from the portfolio when possible.

1. **What is CRUD?** Create, Read, Update and Delete; Golden Crust creates, displays, edits and archives products.
2. **What is the difference between frontend and backend?** The frontend is the interface; the backend processes requests, applies rules and communicates with the database.
3. **What is an API?** A set of routes that lets the browser exchange requests and responses with the server.
4. **What is SQL?** A language for querying and managing relational data; SQLite is the database engine in Golden Crust.
5. **What is a primary key?** A unique identifier for a table row; a foreign key links rows across tables.
6. **Why do we validate data on the server?** Browser checks can be bypassed; server checks protect database rules.
7. **Why use a database transaction?** Related writes should succeed together or fail together; this prevents partial orders and incorrect stock.
8. **What is authentication?** Verifying a user's identity, typically through login credentials; authorization controls what that user may access.
9. **What is an IP address?** A numerical network address; DNS resolves names to network addresses.
10. **What is DHCP?** A protocol that can assign an IP address and other network settings automatically.
11. **How do you troubleshoot no internet?** Check power, Wi-Fi/Ethernet, status, IP configuration, local gateway, DNS and broader connectivity, recording each observation.
12. **What is a SQL injection?** Unsafe concatenation of user input into database statements; parameterized queries reduce the risk.
13. **What is Git compared with GitHub?** Git tracks local changes; GitHub hosts and helps collaborate on repositories.
14. **Why is cloud deployment different from local hosting?** A cloud host runs independently of the student laptop; its storage, environment variables and resource rules may differ.
15. **Why can the free demo lose orders?** The hosted app saves SQLite writes to an ephemeral filesystem; a restart can discard changes.

**Interview method:** State a definition → relate it to a concrete project → mention a limitation or a troubleshooting example.
